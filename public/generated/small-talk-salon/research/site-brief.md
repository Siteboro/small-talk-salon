# Site brief

## Goal

Create a polished sales-preview website for Small Talk Salon that feels specific to a welcoming Madisonville salon rather than a generic beauty template.

## Direction

- Editorial Southern warmth: ivory paper, espresso ink, dusty rose, muted sage, restrained brass.
- Expressive but readable serif display type paired with a clean sans-serif.
- Cinematic image composition using only the salon’s real Google Maps photos.
- Lightweight motion based on transforms and requestAnimationFrame to avoid scroll lag.
- Strong mobile experience with a horizontal swipe gallery and compact navigation.

## Conversion path

1. Establish atmosphere and visual quality.
2. Show service categories without unverified prices.
3. Show real salon work.
4. Reinforce trust with verified Google reviews.
5. Drive calls and directions.
6. Offer the Siteboro preview-purchase CTA without blocking the salon experience.
